# Roadmap

Coding agents must read this file before selecting work. Specs live in `docs/roadmap/`. Do not implement later items while an earlier one is active unless a minimal prerequisite is unavoidable; record that decision here.

## Active

006 Dubbing pt-BR — phase 1 (contracts, `job_kind`, CLI, persistence). Do not start later 006 phases until this lands.

007 Dashboard v2 — Fase 1 (backend only: `/api/overview`, search/filter/sort/pagination on `/api/jobs`, the `progress` stage contract). See `docs/dashboard-v2-audit.md` for the Fase 0 findings this phase is built on. Do not start Fase 2 (new frontend) until this is reviewed.
